## 4. 전문가 라벨 없이 계속 학습 (앱 0.3.2, 모델 0.3)

### 4-1. 장기 근거 투표 (`ml/organ_votes.py`) — 효과 작음, 낮은 가중치로만 반영

- MONDO 교차참조를 개념별 장기 투표로 바꿨다. 출처: ICD-10/9 장, MeSH 2026 질환 범주, DOID 신체계통, HPO 표현형의 장기 가지.
- 투표가 있는 개념: DOID 9,155, HPO 10,401, ICD 3,180, MeSH 2,561.
- 장기 모델 특징으로 넣은 dev 결과: 가중치 3.0은 0.698, 1.0은 0.708, 0.3은 0.713. 투표가 없을 때는 0.706이다.
- dev 차이가 잡음 수준이라 0.3으로만 반영했다.

### 4-2. 후보 재정렬 (`ml/rerank_train.py`) — 채택

**학습 입력**은 gold 개념과 그 부모·자식을 모두 뺐다.
- 외부 말뭉치 train: MedMentions, NCBI, BC5CDR, COMETA
- 1차 Haiku 질의
- 2차 Haiku 질의 3,362개:
  - 25개 에이전트가 개념 1,198개에 대해 동의어, 약어, 오타, 일상어를 썼다.
  - 다른 25개 에이전트가 검토해 70%를 남겼다.
- 합성 오타 4,000개, LRABR 단일 의미 약어
- 정답이 상위 10개 안에 든 질의 약 11,000개를 학습에 썼다.

**모델과 기준값:** 후보 하나당 17개 특징을 쓰는 logistic 회귀다. 받아들임 기준값은 dev에서, 무효 입력 통과율을 현재보다 높이지 않는 조건으로 골랐다.
