# 장기 라벨 v5: GPT 전체 재라벨링 계획과 결과

2026-10-21. 목표는 라벨 정확도 최우선이다(GPT 예산 1만 달러 이상). GPT에게는 `data/curated/concept_organs/v5/GPT_TASK.md` 하나만 주고, GPT가 저장소 안에서 작업을 끝까지 수행한다. 끝나면 Claude가 결과를 가져와 학습에 반영한다.

## 왜 두 단계 라벨인가

- 지금 학습 라벨과 gold는 다장기 질환에서 "장기를 몇 개까지 붙이느냐"가 어긋난다. 학습 가이드대로 라벨링해도 gold와의 상한이 0.945다.
- v5는 장기를 두 단계로 따로 적는다.
  - `primary`: 질환이 생기거나 정의되는 장기. 판단이 거의 갈리지 않는다.
  - `involved`: 질환 자체가 직접 손상시키는 장기. 네 조건을 모두 만족해야 붙인다.
    1. 직접 손상이다.
    2. 환자의 약 30% 이상이거나 주요 진단기준에 들어간다.
    3. 별도 질환으로 진단되는 것이 아니다.
    4. 치료 때문이 아니다.
- 규칙 전문은 `data/curated/concept_organs/GUIDE_v5.md`에 있다. 예시 20개는 모두 gold와 그 상하위가 아닌 질환만 썼다.

## 정확도를 위한 설계

| 장치 | 내용 |
|---|---|
| 근거 자료 | 개념마다 MONDO 이름·동의어·정의·부모·조부모·자식·해부학 위치·특징·원인 유전자·외부 ID를 준다. 10,222개념에는 HPO 표현형과 빈도(phenotype.hpoa 2026-09-02, 빈도 높은 순 최대 40개)도 준다. 정의가 없는 6,778개념 중 3,596개가 HPO로 보완된다 |
| 독립 3회 | 모든 개념을 서로 다른 배치 구성(배치당 25개념)으로 3번 라벨링한다. 호출마다 지시문과 배치 하나만 든 빈 임시 폴더에서 새 Codex 세션으로 실행한다(ChatGPT 구독, gpt-6.1-sol high) |
| 합의 규칙 | 장기 13개 각각의 단계(primary/involved/없음)에 3명 모두 합의해야 확정한다 |
| 판정 | 하나라도 합의가 안 된 개념은 판정 단계로 보낸다. 판정자는 세 라벨, 근거, 이전 라벨(v4, 참고용)을 보고 갈린 장기마다 결정과 이유를 쓴다. 공개 참고자료(OMIM, Orphanet, GeneReviews)를 쓸 수 있다 |
| 감사 | 부모의 정의 장기가 빠진 라벨, v4와 2개 이상 다른 라벨, 낮은 확신, 확정분의 무작위 3%를 엄격하게 다시 본다. 무작위 표본의 수정률이 5%를 넘으면 보고하고 멈춘다 |
| 형식 검사 | 모든 출력을 자동 검사한다(축 이름, 상한, 두 목록 중복, id 순서). 틀리면 문제를 알려주고 다시 묻는다 |
| 평가 격리 | gold 관련 1,822개념도 표시 없이 섞여 있어 GPT는 무엇이 평가용인지 모른다. 평가 데이터 폴더는 열지 못하게 했다 |
| 기록 | 호출마다 모델, 설정, 토큰, 시간을 `v5/runs.jsonl`에 남긴다. 최종 `REPORT.md`에 일치도와 주요 갈림 패턴을 정리한다 |

## 규모와 실행 방식 (ChatGPT 구독)

| 단계 | 세션 수 |
|---|---|
| 3회 패스 | 906배치 × 3 = 2,718회 |
| 판정 | 갈린 개념 수에 따라 다르며, 40%로 가정하면 약 900회 (배치당 10개념) |
| 감사 | 약 300~500회 |

- 동시 세션은 3개(최대 4개)로 둔다.
- 429·403이나 사용량 한도가 오면 전체가 15→30→60분 멈췄다가 이어간다. 구독 한도 때문에 전체가 며칠에서 한 주 이상 걸릴 수 있다.
- **첫 시도(2026-10-20 밤 ~ 10-21 새벽):** 동시 256 세션을 띄워 429와 Cloudflare 403을 받았고, 호출의 72%는 도구 사용으로 거부됐다. 그 결과물은 `provenance/`에 보관만 하고 쓰지 않는다.

## GPT 작업이 끝나면 (Claude)

1. `REPORT.md`와 `agreement.json`을 검토한다.
2. 무작위 200개념을 독립적으로 점검한다(Claude Opus).
3. **gold_v1 만들기:** gold 관련 개념의 GPT 라벨과 Claude의 독립 라벨을 판정해서 만든다. 두 회사의 모델이 따로 라벨링하므로 같은 편향이 학습 라벨과 gold에 함께 들어가는 것을 막는다. `gold_v0`은 그대로 둔다.
4. **합격 기준:** 학습 라벨 규칙과 gold_v1의 장기별 일치 0.97 이상. 지금 0.945인 상한을 올리는 것이 목적이다.
5. **로더 반영:** `primary ∪ involved`를 학습 목표로 쓰고 `primary`를 두 번째 출력으로 학습한다.
6. **재학습:** 영어 우선 설정(Gemma, 가장 좋은 encoder, 결합)으로 다시 학습한다.
7. **재채점:** gold_v0, gold_v1(두 단계 모두), 아는 질환 벤치마크로 채점하고, v4 라벨로 학습한 결과와 나란히 비교한다.

## 결과 (2026-10-22 ~ 10-23)

- **라벨링:** 10-22 09:11에 끝났다. 3,519 세션, 22,638개념이다. 3번 모두 일치한 개념은 19,528개, 판정한 개념은 2,876개, 감사에서 고친 개념은 234개다. 무작위 감사 수정률은 1.6%다. 전체 내용은 [REPORT.md](../../data/curated/concept_organs/v5/REPORT.md)에 있다.
- **gold_v1:** 위 3단계대로 만들었다(`ml/gold_v1.py`). GPT 라벨과 Claude 라벨이 다른 33개념은 두 판정자가 A/B로 봤다.
  - 각 판정자는 자기 회사 모델의 라벨을 더 골랐다(33개 중 26개씩).
  - 그래서 장기마다 두 판정자가 같을 때만 확정하고, 다르면 gold_v0이 정한다.
- **v5.1:** involved에 선천 구조 이상과 환자 1~2명뿐인 빈도가 많이 들어가 규칙 두 개를 더했다([RULE_v5_1.md](../../data/curated/concept_organs/v5/RULE_v5_1.md)).
  - involved 6,384개를 Haiku 두 명이 독립적으로 봤고, 둘 다 빼자고 한 1,375개를 GPT가 다시 봤다.
  - 그중 156개는 GPT가 남기라고 해서 되살렸고, 최종 1,218개를 뺐다(`ml/relabel_v5_1.py`).
- **로더:** `ADCTOX_LABELS=v4`(기본, 앱) / `v5`(primary ∪ involved) / `v5p`(primary만) / `v51` / `v51f`. v5 계열은 모두 gold 관련 개념을 뺀다(`ml/linking_models.py`).
- **재학습 (Gemma E2B S5a 설정, dev 영어, seed 3개 평균):**

|---|---|---|

- 차이는 dev 노이즈(±0.05) 안이다. 합격 기준(라벨 규칙과 gold_v1의 일치 0.97 이상)은 따로 재지 않았다.
- known은 정답이 각자 학습한 라벨표라서 라벨 버전끼리 비교할 수 없다.

- 이후 연구 학습(처음부터 만든 모델, 증류 teacher)은 v5.1을 쓴다. 앱은 아직 v4다.
