# AI 파트 슬라이드·포스터 초안 (2026-10-27)

[competition_plan.md](../../docs/competition_plan.md)의 PPT 구성 중 AI 몫(2~6장, 10장)과 포스터 AI 칸이다. 숫자는 모두 test 값이고, 원자료는 [overview.md](overview.md) 5절과 `ml/results/benchmarks/final_test.json`이다. 팀원은 문장을 다듬어도 되지만 숫자는 바꾸지 않는다.

## 2장. 해결 개요

**제목:** 기저질환 이름 하나로, 이미 손상된 장기와 피해야 할 ADC를 보여 준다

그림(왼쪽 → 오른쪽):
1. 입력: 기저질환 이름(정식 이름, 동의어, 약어, 오타, 일상 표현)
2. 질환 연결: MONDO 질환 2만 2천여 개 중 하나를 찾는다
3. 장기 판정: 13개 장기 중 이미 손상된 장기
4. ADC 비교: 15종 ADC의 라벨 경고(Boxed warning, Warnings and Precautions)와 겹치는 장기, payload 기전(라벨 12.1절 원문)

발표 메모: "독성 확률을 예측하는 것이 아니다. 이미 약한 장기에 라벨이 경고하는 ADC를 표시한다."

## 3장. 데이터와 평가 격리

**제목:** 정답을 미리 본 적 없는 질환으로 평가했다

- 질환 목록: MONDO(질환 온톨로지), 증상: HPO, 이름·정의: UMLS, 문헌: PubMed 초록
- 장기 라벨: 2만 2,638개 질환을 GPT가 독립적으로 3번 라벨링하고, 다르면 판정·감사했다(패스 간 κ 0.94~0.98). 다시 Claude 두 명이 규칙으로 재검토했다(v5.1)
- **평가 1 (gold):** 흔한 기저질환 211개, 600문항. 두 사람이 정답을 합의했다. 이 질환과 그 상·하위 질환은 학습에서 모두 뺐다. → 처음 보는 질환
- **평가 2 (known):** 학습한 질환을 논문 속 다른 표현으로 묻는다. → 아는 질환
- dev로만 튜닝하고, 모델을 정한 뒤 test를 한 번 채점했다

## 4장. AI ①: 처음부터 만든 의학 언어 모델

**제목:** 공개 의학 텍스트만으로 무작위에서 학습한 모델

- 사전학습된 가중치를 쓰지 않았다. BERT-base 구조를 무작위에서 시작해 48시간 사전학습했다(GPU 1장)
- 사전학습 자료: PubMed 초록 86%, UMLS 이름·정의 12%, MONDO·HPO 1%
- 판정 학습: 질환 이름 ↔ 질환 연결, 장기 13개 판정. 영어 오타·약어 쌍 6만 개를 더했다
- 큰 모델(BERT-large, GPU 3장 32시간)도 학습했지만, 점수 차이가 0.001이라 작은 모델을 골랐다

발표 메모: "Gemma 같은 거대 언어 모델을 쓰지 않고도 같은 수준에 도달할 수 있는지가 질문이었다."

## 5장. AI ②: 처음 보는 질환은 기록을 읽고 판정한다

**제목:** 모르는 질환은 이름이 아니라 온톨로지 기록을 읽는다

그림: `docs/images/competition/evidence_example.svg` (gold dev 예시 3개)
- 모델이 처음 보는 질환을 MONDO에 연결하면, 그 질환의 정의·상위 개념·증상 기록을 읽는 두 번째 모델이 장기를 판정한다
- 예: "TUBERCULOSIS" → 이름만 보면 감염만, 기록("the lungs being the most common site")을 읽으면 폐 + 감염
- 효과(dev): 처음 보는 질환 0.690 → 0.754

발표 메모: "사람 의사가 모르는 병을 교과서에서 찾아 읽는 것과 같은 방식이다." 이것이 이 연구의 새로운 점이다.

## 6장. 결과

**제목:** 처음부터 만든 모델이 튜닝한 Gemma와 같은 수준이고, 둘을 합치면 가장 좋다

| test, 장기 macro-F1 | 처음 보는 질환 | 아는 질환 | 평균 |
|---|---|---|---|
| Gemma (튜닝 안 함) | 0.739 | 0.432 | 0.586 |
| Gemma (우리 라벨로 튜닝) | 0.834 | 0.588 | 0.711 |
| **처음부터 만든 모델** | 0.778 | 0.667 | **0.723** |
| **둘을 합친 모델** | 0.836 | 0.674 | **0.755** |

- 처음부터 만든 모델은 아는 질환에서 강하고, Gemma는 처음 보는 질환에서 강하다. 합치면 둘의 장점을 가진다
- 처음부터 만든 모델과 튜닝한 Gemma의 차이(+0.012)는 통계적으로 확실하지 않다. "같은 수준"이라고 말한다
- seed 3개 평균. 문항 수: 처음 보는 질환 296, 아는 질환 168

## 10장. 구현

**제목:** 환자 정보가 PC 밖으로 나가지 않는다

- Windows, macOS, Linux 설치 파일. 인터넷 없이 PC 안에서만 판정한다
- 라벨 경고는 DailyMed 라벨 원문에서 가져오고, 라벨이 바뀌면 업데이트로 반영한다
- 기전 문장은 라벨 12.1절 원문 그대로이며, 프로그램이 원문과 글자 단위로 대조해 확인한다

(앱 화면 캡처 1장: 기저질환 입력 → 장기 → ADC 표)

## 포스터 AI 칸 (약 150단어)

**AI 방법.** 기저질환 이름을 MONDO 질환에 연결하고, 13개 장기 중 이미 손상된 장기를 판정한다. 판정 모델은 사전학습 가중치 없이 공개 의학 텍스트(PubMed, UMLS, MONDO, HPO)만으로 처음부터 학습했다. 처음 보는 질환은 연결된 질환의 온톨로지 기록(정의, 상위 개념, 증상)을 두 번째 모델이 읽어 판정한다. 평가 질환과 그 상·하위 질환은 학습에서 모두 뺐다.

**결과 (test, 장기 macro-F1).** 처음부터 만든 모델 0.723, 튜닝한 Gemma 0.711, 튜닝 안 한 Gemma 0.586. 둘을 합친 모델 0.755. 모든 계산은 PC 안에서 이뤄진다.

## 예상 질문 (AI)

| 질문 | 답 |
|---|---|
| Gemma보다 낫다고 할 수 있나요? | 평균은 조금 높지만 통계적으로 확실하지 않다. 같은 수준이고, 합친 모델이 가장 높다 |
| 라벨을 GPT가 만들었으면 LLM 지식이 들어간 것 아닌가요? | 라벨은 정답표다. 모델의 지식은 공개 텍스트 사전학습에서 왔다. 라벨 품질은 전문가 검증(7장)으로 확인한다 |
| 처음 보는 질환을 어떻게 판정하나요? | 질환 이름을 온톨로지에 연결하고, 그 질환의 기록을 읽는다(5장) |
| 왜 큰 모델을 쓰지 않았나요? | BERT-large도 학습했지만 차이가 0.001이었다. 미리 정한 규칙대로 작은 모델을 썼다 |
