## 모든 파일 공통 규칙

1. **파일을 받으면 먼저 복사해서 이름 뒤에 본인 이름을 붙입니다.** 예: `1_장기판정_검토_김철수.csv`
2. **저장할 때는 "CSV UTF-8 (쉼표로 분리)" 형식으로 저장합니다.** 엑셀에서 "다른 이름으로 저장" → 파일 형식에서 고릅니다. 그냥 "CSV"로 저장해도 대부분 읽을 수 있지만, 특수문자가 깨질 수 있습니다.
3. **"(수정 금지)"라고 적힌 열은 절대 고치지 않습니다.** 줄 순서를 바꾸거나(정렬) 줄을 지우지도 않습니다. 열 너비를 바꾸거나 숨기는 것은 괜찮습니다.
4. **"두 사람이 각자" 표시된 파일은 서로 상의하지 않고 따로 채웁니다.** 두 사람의 답이 같은 줄만 쓰고, 다른 줄은 세 번째 분께 따로 여쭙니다. 그래서 상의하면 오히려 품질 확인이 안 됩니다.
5. **확실하지 않으면 "모르겠음"이나 빈칸으로 둡니다.** 억지로 고른 답보다 빈칸이 낫습니다.
6. 교과서, 진료 지침, 검색은 참고해도 됩니다. **ChatGPT 같은 AI 답변은 쓰지 않습니다.** 사람의 판단이 필요한 자료라서, AI 답을 옮기면 쓸모가 없어집니다.
7. 다 못 채웠어도 위에서부터 채운 만큼 돌려주시면 됩니다.
8. 환자 이름, 등록번호, 생년월일 같은 개인 정보는 어떤 파일에도 적지 않습니다.

## 1. 장기 판정 검토 (`1_장기판정_검토.csv`)

**목적:** 프로그램이 질환을 찾은 뒤 "이 질환은 어느 장기 문제인가"를 정하는데, 여기서 틀리는 경우가 가장 많습니다. 사람이 정한 정답이 필요합니다.

**칸 채우는 법**
- 한 줄이 질환 하나입니다. `질환 이름`(영어)과 `설명(참고)`을 읽습니다.
- 그 질환이 **직접 손상하거나 자리 잡는 장기** 칸에 `O`를 적습니다. 최대 4개입니다.
- 13개 장기 중 어디에도 해당하지 않으면 `해당 장기 없음`에 `O`(예: 순수 정신과 질환, 생식기만의 질환).
- 판단할 수 없으면 `모르겠음`에 `O`.
- `검토자`에 이름, 할 말이 있으면 `메모`에.

**장기 칸의 뜻**

| 칸 | 넣는 것 | 예 |
|---|---|---|
| 혈액 | 혈구, 골수, 응고 | 빈혈, 혈소판감소증, 백혈병, 림프종 |
| 간 | 간, 담도 | 간염, 간경변, 담도 질환 (담석은 간 + 위장관) |
| 심장혈관 | 심장, 혈관, 혈전, 고혈압, 혈관성 뇌졸중 | 심부전, 부정맥, 심부정맥혈전증 |
| 폐 | 폐, 기도 | 천식, COPD, 간질성 폐질환 |
| 신장 | 콩팥 | 만성 콩팥병, 사구체신염 |
| 위장관 | 식도, 위, 장, 췌장 | 크론병, 궤양성 대장염, 췌장염 |
| 신경 | 뇌, 척수, 말초신경 | 뇌전증, 파킨슨병, 말초신경병증, 뇌종양 |
| 눈 | 눈 | 녹내장, 망막병증 |
| 피부 | 피부 | 건선, 아토피, 피부 흑색종 |
| 대사내분비 | 내분비샘, 당뇨, 지질, 전해질 | 당뇨병, 갑상샘기능저하증 |
| 근골격 | 뼈, 관절, 근육 | 골다공증, 류마티스 관절염, 골육종 |
| 감염면역 | 감염, 면역결핍, 자가면역 | 결핵, HIV, 루푸스 (침범 장기와 **함께** 표시) |
| 귀 | 귀, 청력 | 난청, 이명 |

**판단 기준**
- "약물 부작용이 더해지면 이미 아픈 장기에 겹치는 곳"을 생각하면 됩니다.
- **드문 합병증이나 나중에 생길 수 있는 장기는 넣지 않습니다.** 예: 2형 당뇨병만 있으면 `대사내분비`만. 신장은 넣지 않습니다.
- 종양은 종양이 있는 장기입니다. 예: 뇌종양 → 신경, 골육종 → 근골격.
- 자가면역 질환은 침범 장기와 `감염면역`을 함께 표시합니다. 예: 루푸스 신염 → 신장 + 감염면역.

**예시**

| 질환 이름 | 혈액 | 간 | 심장혈관 | 신장 | 대사내분비 | 감염면역 | 해당 장기 없음 |
|---|---|---|---|---|---|---|---|
| type 2 diabetes mellitus | | | | | O | | |
| lupus nephritis | | | | O | | O | |
| bipolar disorder | | | | | | | O |

## 2. 정답 후보 고르기 (`2_정답후보_고르기.csv`)

**목적:** 사람들이 줄임말, 오타, 일상 표현으로 질환을 적었을 때 프로그램이 맞는 질환을 고르는지 가르치는 자료입니다.

**칸 채우는 법**
- `입력`이 누군가 적은 말입니다(영어 줄임말, 오타, 일상 표현).
- `후보1`~`후보6` 중 그 말이 뜻하는 질환의 **번호**를 `정답 번호` 칸에 적습니다(1~6).
- 후보 중에 정답이 없으면 `0`을 적고, 알면 `정답이 없을 때 정답 질환 이름`에 정답을 적습니다.
- 여러 후보가 다 맞아 보이면 **가장 정확한 것 하나**를 고릅니다. 예: "type 2 diabetes mellitus"와 "diabetes mellitus"가 있고 입력이 "T2DM"이면 type 2 쪽.
- 무슨 뜻인지 모르겠으면 빈칸으로 둡니다.
- 후보 순서는 일부러 섞어 두었습니다. 위에 있다고 더 그럴듯한 것이 아닙니다.

**예시**

| 입력 | 후보1 | 후보2 | 후보3 | … | 정답 번호 |
|---|---|---|---|---|---|
| CKD | acute kidney injury | chronic kidney disease | kidney cancer | | 2 |
| hart attack | myocardial infarction | heart failure | cardiac arrest | | 1 |

## 3. 실제 입력 모으기 (`3_실제입력_수집.csv`, `3b_실제입력_정답고르기.csv`)

**목적:** 지금까지의 시험 문제는 사람이 아니라 컴퓨터가 상상해서 만든 것이라, 실제 현장에서 쓰는 말과 다를 수 있습니다. 진짜 표현으로 시험해야 정말 나아졌는지 알 수 있습니다.

**모으는 법 (3번)**
- 종양내과 의료진, 연구 간호사, 약사 등에게 "ADC 치료를 고려하는 환자의 기저질환을 차트에 쓰듯 적어 주세요"라고 부탁합니다.
- `입력한 그대로`에는 **받은 그대로**(띄어쓰기, 오타, 줄임말 포함) 적습니다. 고치지 않습니다.
- `뜻하는 질환`에는 적은 사람에게 물어 정식 이름을 적습니다(한글 가능).
- 한국어 표현을 많이 모아 주세요. 지금은 한국어 시험 문제가 하나도 없습니다(목표: 전체 300개 이상, 그중 한국어 200개 이상).
- 예시 두 줄은 지우고 씁니다.

**정답 고르기 (3b)**
- 3번을 돌려주시면, 프로그램이 찾은 후보를 붙여 `3b` 파일을 따로 보내 드립니다.
- 2번처럼 정답 번호를 고르고, 1번처럼 장기 칸에 O를 표시합니다.
- 뜻이 여러 개라 정할 수 없는 표현(예: "asd"는 심방중격결손일 수도, 자폐일 수도 있음)은 `뜻이 여러 개라 정할 수 없음`에 O.

### FinnGen 자료를 주신 분께 여쭐 것

1. 이 표가 FinnGen 몇 번째 릴리스(R10이 맞는지)에서, 어떤 분석 결과(예: Risteys 생존분석)를 가져온 것인지.
2. 질환 쌍을 어떤 기준으로 골랐는지. 지금 표에는 가능한 쌍의 7%만 있고 대부분 통계적으로 유의한 쌍입니다. 유의한 쌍만 고른 것인지, 상위 몇 개만 고른 것인지.

4. 각 쌍의 환자 수와 기간(0/1/5/15년)의 정확한 뜻, 성별이나 나이로 나눈 결과가 있는지.

## 돌려주는 법

- 채운 파일(본인 이름이 붙은 것)을 담당자에게 메일이나 공유 폴더로 보냅니다.
- 1번, 2번, 3b는 **두 사람의 파일을 각각** 보냅니다. 합치지 않습니다.
- 두 사람의 답이 다른 줄은 같은 모양의 새 파일(`..._불일치_날짜.csv`)로 세 번째 분께 보내 드립니다. 세 번째 분은 그 파일만 채우면 됩니다.
- 파일을 받으면 담당자가 자동 검사를 돌립니다. 표시가 잘못된 줄(예: 장기와 "해당 장기 없음"을 함께 표시)은 몇 번째 줄인지 알려 드리니 그 줄만 고쳐 주시면 됩니다.
