ADCTOX 0.5.2: 결과 화면 오류 수정.

- **결과 화면이 다시 열린다.** 0.5.0과 0.5.1에서는 결과 화면으로 넘어갈 때 앱이 `NameError: __file__`로 멈췄다. ADC의 payload·linker 표를 저장소 경로에서 읽으려 했기 때문이다. 이제 표가 앱 파일 안에 들어 있다.
- **옵션 값이 잘못되면 오류 메시지를 보여 준다.** `--lab hb=abc`, `--lab hb`, 값 없는 `--crcl`, `--priority a`는 무엇을 읽지 못했는지 알려 주고 코드 2로 끝난다. 검사 수치 단계에서 숫자가 아닌 값을 넣으면 "숫자를 입력하세요"가 나온다.
- **검색 목록에서 고른 질환에 라벨도 MONDO 기록도 없으면** 이름을 직접 입력했을 때처럼 판정 모델이 이름으로 장기를 정한다(`Chosen · name`).

모델은 그대로 0.7이다.

```bash
adctox --update-app
```
