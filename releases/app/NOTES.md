ADCTOX 0.5.1: 앱이 판정 모델과 같은 방식으로 질환을 읽는다.

모델 0.7(`ScratchJudge/`)에서 질환이 어떤 길로 들어와도 판정 모델과 같은 장기가 나온다. gold dev 304문항 중 앱과 판정 모델이 다른 문항이 6개에서 1개로 줄었다. 남은 1개는 등록된 맥락 조건(anthracycline exposure)이다.
- **검색 목록에서 고른 질환:** 판정 모델의 장기(v5.1 장기 라벨, 또는 MONDO 기록을 읽은 판정)를 쓴다. 이전에는 예전 MONDO 분류표를 썼다. 판정 모델에 장기가 있는 21,238개 질환 중 8,121개에서 둘이 달랐다. Read as 칸 끝에도 `label` 또는 `record`가 붙는다.
- **등록 질환 이름이 비슷해도 판정 모델의 MONDO 연결이 우선한다.** 예: 'Type 1 diabetes mellitus'가 등록 질환 'Type 2 diabetes'로 읽혀 면역 장기가 빠지던 문제. 판정 모델이 같은 질환에 연결하거나 MONDO에 연결하지 않는 입력(이전 노출, 시술)은 이전처럼 등록 질환과 이름으로 맞춘다.
- **판정 모델의 MONDO 연결은 판정 모델 자체 기준(0.65)으로 인정한다.** 판정 모델이 "장기 없음"으로 본 입력에 비슷한 등록 질환의 장기를 빌려 오지 않는다.

모델은 그대로 0.7이다.

```bash
adctox --update-app
```
