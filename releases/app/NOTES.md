ADCTOX 0.5.3: 입력은 화면에서만.

- **명령줄로 질환이나 검사 수치를 넣는 기능을 없앴다.** `adctox cirrhosis --lab hb=8`, `--crcl`, `--child-pugh`, `--priority`, `--detail`, `--list`는 더 이상 받지 않는다. 이런 인자를 주면 입력 화면을 쓰라는 안내와 함께 코드 2로 끝난다. 확인되지 않은 입력으로 결과가 나오던 경우(터미널이 없을 때 예시 환자 ILD로 분석, 철자가 틀린 `--lab` 무시, `--crcl -10 --child-pugh Z` 그대로 사용)도 함께 사라졌다.
- `adctox --self-test`는 고정된 예시 환자(alzheimer, cirrhosis, 치매)의 표를 출력한다. `--plain`은 질문-답 입력을 유지하고, 빈 질환 줄은 예시 환자를 채우지 않고 끝난다.
- **결과 화면의 Key values에 입력한 검사 수치가 모두 나온다.** 장기를 표시한 수치는 `Hb 8 g/dL → Blood`처럼 보인다. 전에는 사용된 수치도 "Not entered"로 나올 수 있었다.
- **저장된 입력을 몰래 불러오지 않는다.** 시작할 때 저장된 질환과 검사 수치 개수, 파일 위치를 보여 주고 "이어서 하기" 또는 "새 환자로 시작(저장된 입력 지움)"을 고른다.
- pyproject.toml의 버전이 앱 버전과 같아졌다. README에 AI 판정은 영어 입력으로만 평가했다는 점과 입력 저장 위치를 적었다.

모델은 그대로 0.7이다.

```bash
adctox --update-app
```
