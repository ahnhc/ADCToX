ADCTOX 0.3.13: 화면 정리.

- **영어로 되돌림:** 결과표와 장기 이름처럼 영어로 읽는 편이 자연스러운 용어(Label restriction, Patient organs, Monitor/Avoid, Liver/Kidney ...). 한국어는 안내 문구에만 쓴다.
- **첫 화면:** 질환 이름은 입력한 언어로 먼저 나오고, 다른 언어는 흐리게 뒤에 붙는다. 증상 문장을 입력하면 찾은 질환이 맨 위에 와서 Enter로 바로 고를 수 있다.
- **AI 장기 분석:** Input / Organs / Read as 세 칸으로 보여 준다.
- **결과 화면:** 아래 단축키 안내에 각 키가 하는 일을 적었다.

```bash
adctox --update-app
```
