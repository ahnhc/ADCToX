ADCTOX 0.3.23: 유효 입력 기준 0.95, 질환 중복 정리.

- **유효 입력 기준 0.95:** "간이 안좋아요" 같은 흔한 증상 표현이 더 이상 무효로 걸리지 않는다. 한국어 dev 점수가 0.705에서 0.743으로 올랐고, 평가셋의 무효 입력은 여전히 하나도 통과하지 않는다. 다만 일부 은어(심통, 뇌절)는 이제 장기가 붙을 수 있다.
- **질환 중복 제거:** 같은 질환이 검색 목록에 두 번 나오지 않는다(예: Heart failure). 이미 추가한 질환도 목록에서 빠진다.

```bash
adctox --update-app
```
