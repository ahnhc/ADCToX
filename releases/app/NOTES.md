ADCTOX 0.6.6: 설명 문장을 빼고 표시와 막대로 보이게 했다. Ubuntu, macOS, Windows 모두 0.6.6이다.

- **화면의 설명 문장을 뺐다.** 첫 화면 소개, 검사 수치와 우선순위 안내, % 설명, Review order 설명이 없다. 자동 (질환 중증도 순)은 `Auto`다.
- **AI 장기 분석은 % 대신 막대다.** 장기 이름 칸 너비를 맞춰 모든 행의 막대가 같은 자리에서 시작한다.
- **Review order는 번호 없이 칩과 →로 보인다.** 먼저 볼 장기는 채운 칩, 다음 장기는 테두리 칩이다.
- **Indication은 ✓(초록) 또는 ✕(주황)와 암종 이름이다.**
- **검사 수치는 칸 모양으로 상태를 보인다.** 빈 칸은 흐린 점선, 기준 안의 값은 초록 테두리와 ✓, 기준을 넘은 값은 주황 테두리와 `→ 장기`다.

모델은 그대로 0.7이다.

```bash
adctox --update-app
```
